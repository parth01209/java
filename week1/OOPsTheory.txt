1. Class
A class is a blueprint or template for creating objects.
It defines the structure (fields/attributes) and behavior (methods) that its objects will have.

Characteristics of a Class

It acts as a template for creating objects.
Defines properties (data members) and methods (functions).
Does not consume memory until an object is created.

2. Object

An object is an instance of a class. It represents a real-world entity and contains:

State: Represented by attributes/fields.
Behavior: Represented by methods/functions.

Characteristics of an Object

Consumes memory when instantiated.
Each object has its own values for fields defined by the class.
